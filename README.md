# song-planner（演奏したい曲リスト）

「いつか弾きたい曲」を登録して、取り組む順番と日程まで見通せるようにするWebツールです。
スマホで使うことを前提にした、1画面アプリ型のUIになっています。

**▶ 使ってみる（GitHub Pages）: https://hrtnmt.github.io/song-planner/**

## 主な機能

### 曲の管理
- 曲名・作曲者・時代・作曲年・区分（吹奏楽／ピアノ／器楽ソロ／室内楽／管弦楽／合唱／その他）・弾きたい度（★1〜3）・メモを登録
- ステータスは5段階（いつか／未着手／譜読み中／仕上げ中／演奏済み）。段階チップがそのまま進捗ゲージ兼「次の段階へ」ボタンになっていて、演奏済みにするとカードにCLEARスタンプが落ちる、ゲームっぽい操作感
- 検索、区分／ステータス／時代での絞り込み、作曲者順・時代順・作曲年順などのソート
- ピティナ・ピアノ曲事典への検索リンクと、難易度・演奏時間・曲ページURLの記録欄

### ロードマップ
- 曲同士を「前提関係」でつなぐ流れ図。ワークスペースを複数作って曲を出し入れできる
- 接続はタップ選択式の「つなぐモード」：前提にしたい曲をタップで選び（複数選べばAND、1枚ならORの選択肢）、対象をタップして確定。グループ同士の接続も可能
- 「整列」ボタンで依存関係の深さ順に自動配置。カードはドラッグで自由に移動でき、画面の端まで運ぶと自動でパンする
- 全体図（縮小ビュー）：時代ごとに図形と色を変えて表示し、タップで詳細確認・ステータス変更

### 予定と目安
- 譜読み開始日・仕上げ期限・本番（名前付き、複数可）を登録し、予定一覧と残り日数を表示
- 各日程からGoogleカレンダー追加／.ics書き出し（7日前・3日前・前日のアラーム付き）ができる
- 日程のない曲には「目安スケジュール」を自動推定して薄く表示（本番から4ヶ月逆算＝譜読み3ヶ月＋仕上げ1ヶ月、またはロードマップのつながりから推定）

### プロフィール／ログイン／データ
- プロフィール分け（名前＋任意の4桁PINロック）。リストごとにデータを分けて持てる
- Googleログイン（Firebase Authentication）に対応 ※データのクラウド同期は実装中
- 「サンプルを読み込む」ボタンで、同梱の `Sample.json` を試作用プロフィールとして追加できる
- JSONの書き出し／読み込みでバックアップと移行が可能

## データの保存について
- 現在の保存先はブラウザ内（localStorage）です。端末間では共有されません
- 通知は、ページを開いた時のアラート表示と、カレンダー側のリマインダーのみです（プッシュ通知はありません）
