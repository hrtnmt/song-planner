# song-planner — GitHub Pages

「演奏したい曲リスト」の静的版（Pages用ブランチ `gh-pages`）です。
本体のソースコードは `main` ブランチを見てください。

## バージョン

- **α版**（2026-11-06 リリース、同日更新）

α版の内容:
- 曲の登録・検索・絞り込み、作曲者順／時代順／作曲年順ソート
- ロードマップ（前提曲のAND／OR接続、ドラッグで接続、ワークスペース分け）
- ロードマップ全体図（縮小ビュー）：時代ごとに図形と色で表示し、タップで詳細表示
- ステータスは5段階（いつか／未着手／譜読み中／仕上げ中／演奏済み）で、段階ごとに枠・色・アイコンが変化。目安は段階に合わせて残りの節目だけを表示し、過ぎた目安もグレーアウトせず「目安を過ぎています」と表示
- 日付管理（譜読み開始・仕上げ期限・本番）と予定一覧、カレンダー追加ボタン／.ics書き出し
- 日程未設定の曲への「目安」表示（本番から4ヶ月逆算、またはロードマップのつながりから推定。譜読み3ヶ月＋仕上げ1ヶ月）
- プロフィール分け（名前＋任意の4桁PIN）
- スマホ向け1画面アプリレイアウト（下部タブバー、内部スクロール）
- 操作感の調整（説明文を削減し余白を拡大、押下アニメーションと振動フィードバック）
- ロードマップは画面一面表示（初期倍率は55%下限で読みやすい大きさ、上部バーに隠れない初期位置、拡大・縮小と全体フィットのボタン付き）

注意事項:
- 保存先はブラウザ内（localStorage）です。端末間では共有されません。JSONの書き出し／読み込みで移行できます。
- 通知はページを開いた時のアラート表示と、カレンダー追加によるリマインダーのみです（プッシュ通知・メール通知はありません）。
- α版のため、仕様は予告なく変わることがあります。
