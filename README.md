# song-planner （演奏したい曲リスト）

演奏したい曲を登録できるWebツール。

**▶ 使ってみる（GitHub Pages）: https://hrtnmt.github.io/song-planner/**

Pages版は静的版です。保存先はブラウザ内（localStorage）で、各日程からはGoogleカレンダー追加ボタン／.ics（7日前・3日前・前日のアラーム付き）でカレンダーに渡せます。

## 機能
- 曲名・作曲者・ジャンル/編成・ステータス（いつか演奏したい／練習中／演奏済み）・弾きたい度（★1〜3）・メモの登録
- 検索、ジャンル／ステータス／時代での絞り込み、作曲者順・時代順・弾きたい度順などのソート
- ロードマップ：曲同士を前提関係でつなぐ流れ図（複数前提はAND、別グループはORとして金色の矢印で表示、循環は自動で拒否）
- ピティナ・ピアノ曲事典（enc.piano.or.jp）の公式キーワード検索へのリンク
- 譜読み開始日・仕上げ期限・本番（名前付き）の登録、予定一覧と残り日数表示

## 構成
- `client/` — React + TypeScript フロントエンド
- `server/` — サーバー側アクションとスキーマ
- `drizzle/` — DBマイグレーション

> このリポジトリは Muse 上で作成したWebアプリのソースコード保管用です。Museのホスト環境（DB・通知ジョブ）自体は含まれません。
