# song-planner — GitHub Pages

「演奏したい曲リスト」の公開版（`gh-pages` ブランチ）です。
プロジェクト全体の説明は `main` ブランチの README を見てください。

**公開URL: https://hrtnmt.github.io/song-planner/**

## このブランチの内容
- `index.html` — アプリ本体（単一ファイル）
- `Sample.json` — 「サンプルを読み込む」ボタンで取り込む試作用データ

## 現在の版について
- 2026-11-06 に α版をリリースし、以後も更新を続けています
- ステータス5段階（いつか／未着手／譜読み中／仕上げ中／演奏済み）と、段階チップ自体が進捗ゲージになるゲーム風の操作感
- ロードマップ：ワークスペース複数対応、タップ選択式の「つなぐモード」（AND／OR、グループ同士の接続）、「整列」ボタン、全体図
- 日程管理と目安スケジュールの自動推定、カレンダー追加／.ics書き出し
- プロフィール分け（PINロック）、Googleログイン（β準備中。クラウド同期は実装中）
- スマホ向け1画面アプリレイアウト

## 注意事項
- 保存先はブラウザ内（localStorage）です。端末間では共有されません。JSONの書き出し／読み込みで移行できます
- 通知はページを開いた時のアラート表示と、カレンダー追加によるリマインダーのみです（プッシュ通知・メール通知はありません）
- 開発中のため、仕様は予告なく変わることがあります
